## Epic Specification

**Full spec:**
`docs/phases/P2__First_Real_Run/P2-M2-E2.1__spec__write-file-list-dir-and-housekeeping.md`
(git-tracked on `milestone/M2`)

### Prerequisite Verification (do this first)

Before relying on the spec, confirm it — and this Epic's prerequisite artifacts — are
**git-tracked on the expected branch** using `git ls-files --error-unmatch <path>` run on
`milestone/M2`, not a disk-existence check. Disk presence is not proof of commit. If any
path is untracked, STOP and report to the Milestone Chat before proceeding.

Verify on `milestone/M2`:
- `docs/phases/P2__First_Real_Run/P2-M2-E2.1__spec__write-file-list-dir-and-housekeeping.md`
- `local_agent_runner/tools.py` (E1.3, merged — `ToolPermissions`, `ToolResult`,
  `execute_tool`, `_checked_file`, `_require_string`, `_cap_stream`, `OUTPUT_CAP`)
- `tests/test_check_transcript.py` (E1.5, merged — contains the `test_step` helper this
  Epic renames)

### Summary

Add `write_file(path, content)` and `list_dir(path)` to the existing tool library, both
scoped by the same `allow_paths` mechanism `read_file`/`edit_file` already enforce
(resolved-absolute-path glob matching, deny by default, traversal-safe). Rename the
pytest-collectible `test_step` helper in `tests/test_check_transcript.py` to `run_step`
so it stops being collected as a test and the suite's `PytestReturnNotNoneWarning`
disappears.

### Problem Statement

A real Epic cannot yet create files or inspect directories — `write_file` and `list_dir`
don't exist. Separately, `tests/test_check_transcript.py::test_step` is a step-builder
helper, not a test, but its name matches pytest's `test_*` collection pattern and it
returns a `dict` instead of `None`, so pytest warns on every run. The Phase spec requires
this fixed in P2's first epic.

### Goals

1. `write_file(path, content)`: creates a new file or overwrites an existing one,
   creating missing parent directories, scoped by `allow_paths`
2. `list_dir(path)`: lists a directory's immediate entries (sorted, subdirectories
   `/`-suffixed), scoped by `allow_paths`
3. Identical `allow_paths` enforcement semantics across all four file tools
   (`read_file`, `edit_file`, `write_file`, `list_dir`)
4. `tests/test_check_transcript.py::test_step` renamed to `run_step` throughout (a pure
   rename, all call sites) — no more pytest collection, no more warning
5. Offline unit tests for both new tools (temp dirs, no GPU/Ollama/network)
